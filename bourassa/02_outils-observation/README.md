# 02 · Outils d'observation — Observer ses élèves

Outils professionnels pour l'enseignant·e qui souhaite observer un·e élève à travers la grille du Profil Apprenant, au-delà de l'auto-évaluation par questionnaire.

Ces outils s'utilisent **après** s'être approprié·e le modèle via `01_profil-apprenant/` : on ne diagnostique pas un·e élève sans avoir compris d'abord soi-même de quoi l'on parle.

---

## 📄 Outils d'observation directe

### `Grille_observation_meta.pdf` — Axe arrière / avant
Grille d'observation centrée sur l'axe métacognitif.
Pour chaque comportement observable, choix entre :
- **Pôle arrière** — *laisse-moi y penser* (lire, examiner, redire, réfléchir avant d'agir)
- **Pôle avant** — *laisse-moi essayer* (tenter, comprendre vite, donner un exemple, se lancer)

Trois colonnes de cotation (1 · 2 · 3) permettent de nuancer la fréquence du comportement observé.

### `Tableau_4-1_Enonce_Ponderation_Actions.pdf` — Cadre à trois temps
Canevas pour construire, avec l'élève ou pour soi-même, un objectif de progression à trois temps :
- **Temps 1** — Énoncer l'objectif
- **Temps 2** — Évaluer la situation actuelle et anticipée (échelle 0-6 avec les 6 pôles illustrés)
- **Temps 3** — Planifier les actions concrètes

Le cadre comprend deux objectifs parallèles pour permettre la comparaison (ex. matière A / matière B).

## 📂 Sous-dossier `schemas_fonctions_dysfonctions/` — Diagnostic professionnel

Six schémas circulaires organisés par axe, en paires **fonctions / dysfonctions**. Ce sont des outils de diagnostic professionnel fin : quand le profil d'un·e élève révèle une **dominance** ou **surdominance** sur un pôle, ces schémas permettent de nommer précisément :
- ce que le pôle fait bien quand il est sollicité (fonctions)
- ce qui se passe quand il est (sur)dominant au détriment de son contraire (dysfonctions)

| Axe | Fonctions | Dysfonctions |
|---|---|---|
| **Cognitif** (gauche / droit) | `Axe_cognitif_13-7_Fonctions.pdf` | `Axe_cognitif_14-1_Dysfonctions.pdf` |
| **Métacognitif** (arrière / avant) | `Axe_metacognitif_22-3_Fonctions.pdf` | `Axe_metacognitif_23-5_Dysfonctions.pdf` |
| **Affectif** (haut / bas) | `Axe_affectif_18-1_Fonctions.pdf` | `Axe_affectif_19-1_Dysfonctions.pdf` |

### Usage typique
1. L'élève remplit le questionnaire → résultat : *surdominance avant +10*.
2. Je consulte `Axe_metacognitif_23-5_Dysfonctions.pdf` → je reconnais « Impulsif, brouillon · Veut essayer avant de comprendre · Refait en boucles la même erreur · Répète : *je veux en finir* ».
3. Je nomme la dysfonction avec l'élève en appui sur le schéma.
4. Je prépare une différenciation à partir du pôle opposé (cf. principe de « prise d'appui croisée » développé dans le Cahier des pôles).

---

## 🎯 Usages possibles

- **Observation en classe** — remplir la grille méta pour un·e élève en difficulté pour objectiver une hypothèse de profil.
- **Entretien individuel** — utiliser le tableau 4.1 comme support de conversation pour co-construire un objectif de progression.
- **Préparation d'une différenciation** — repérer les appuis à mobiliser sur l'axe opposé via les schémas fonctions/dysfonctions.
- **Analyse de cas en équipe** — les schémas servent de référentiel partagé pour discuter un cas en conseil de classe.
