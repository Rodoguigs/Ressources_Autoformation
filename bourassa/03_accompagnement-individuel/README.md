# 03 · Accompagnement individuel — L'entretien socratique

Outils pour l'enseignant·e qui accompagne un·e élève en entretien individuel, pédagogique ou de soutien. L'approche socratique consiste à poser les **bonnes questions** pour que l'élève active lui-même le pôle qu'il n'a pas spontanément sollicité — plutôt que de lui dicter la solution.

Ces outils prolongent naturellement `02_outils-observation/` : une fois le profil nommé, ces supports donnent les mots pour l'accompagner.

---

## 📄 Documents

### `Figure_6-7_Questions_sur_les_poles.pdf`
**L'outil pivot de l'accompagnement.** Tableau à six cases, un par pôle, qui donne pour chacun :
- La **plainte caractéristique** de l'élève (ex. pour le pôle arrière : *« si je ne sais pas tout, je ne sais rien »*)
- La **question socratique** à lui poser pour qu'il active son opposé (ex. *« comment faire pour établir des liens entre mes actions et mes savoirs ? »*)

Usage : repérer la plainte récurrente de l'élève, lui retourner la question correspondante pour déclencher la recherche d'une action nouvelle.

### `Figure_6-9_Actions_sur_les_poles.pdf` — Roue des compétences
Schéma en étoile à six branches qui liste les **savoir-faire** associés à chaque pôle du profil :
- Pôle gauche → je sais utiliser le mot exact, me situer dans le temps, percevoir les différences…
- Pôle droit → je sais percevoir les ressemblances, me situer dans l'espace, produire des idées nouvelles…
- Pôle arrière → je sais sélectionner, planifier, examiner avec méthode…
- Pôle avant → je sais appliquer les procédures, contrôler mon impulsivité, vérifier…
- Pôle haut → je me réinterroge, je surmonte les difficultés…
- Pôle bas → j'y trouve du plaisir, je tente de contrôler ma frustration…

Usage : présenter à l'élève les **ressources** disponibles sur l'axe opposé à son pôle dominant.

### `Figure_7-2_Synthese_fonctions_questions.pdf` — Aide-mémoire de synthèse
Synthèse combinée des fonctions et des questions à poser pour chaque pôle. Outil de référence à avoir sous la main pendant un entretien.

### `Echelles_socratiques.docx` — Échelles graduées éditables
Fichier Word contenant des **échelles socratiques** (de 0 à 10 typiquement) qui permettent à l'élève de se positionner sur une dimension donnée avant/après un travail, et de nommer ce qui se passerait pour qu'il progresse d'un cran.

Usage : co-construction d'objectifs de progression avec l'élève lui-même.

---

## 🎯 Déroulé type d'un entretien socratique (30-45 min)

1. **Observation préalable** — l'élève a rempli le questionnaire ou j'ai observé son profil.
2. **Nommer** — je montre à l'élève la roue du profil et les plaintes caractéristiques (`Figure_6-7`).
3. **Questionner** — je lui pose la question socratique correspondant à sa plainte dominante.
4. **Explorer les ressources** — nous regardons ensemble la roue des compétences (`Figure_6-9`) pour identifier une compétence de l'axe opposé à mobiliser.
5. **Pondérer** — nous utilisons une échelle socratique (`Echelles_socratiques.docx`) pour évaluer la situation actuelle et anticipée.
6. **Planifier** — nous formulons 1 à 3 actions concrètes (couplé avec `02_outils-observation/Tableau_4-1`).
